# Read with questions, not a checklist of links

Refactoring.Guru supplies broader pattern explanations. Our lessons connect selected readings to this calculator with original code and exercises. No paid resource is required.

Use diagrams on the original site, then draw your own mapping. Do not assume all boxes must become separate classes in a small application. Compare purpose, responsibilities, and tradeoffs.

A useful reading note contains: problem → proposed arrangement → calculator mapping → benefit → cost. Link the original page when describing its general concept; distinguish that from your own implementation decisions.

For Python/pandas/pytest details use the official documentation linked inside each lesson. Design readings and API references answer different questions.
